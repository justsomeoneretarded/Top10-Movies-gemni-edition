# Plot-first narration and verified footage discovery

Input stays the same: title, year and the existing workflow controls. A director or source link is not required from the user.

Default reviews explain who the story follows, what happens, what they want and what stands in their way, in plain spoken English. Production credits, ratings, taglines and reception remain in research metadata where useful; they are not the default narration material. Character roles remain available. Mixed source sentences must retain useful story information. This uses story-focused context and editorial instructions, rather than replacing one generic adjective with another. Short useful material stays valid; duration guidance does not require padding.

Footage discovery includes dated and year-free queries, with each title's verified genres and context. Its bounded candidate allowance is shared across query types so early trailer searches do not exclude every scene search. Cast or crew names can help as optional context; a director's name is not mandatory. Source verification still distinguishes the correct production from remakes, other seasons, reactions, AI concepts and full-film uploads.

Festival and theatrical dates can differ. Additional accepted years require dated records for the same verified movie ID or exact release quotations from its verified public page. A bare list of years, a shared title or a guessed neighboring year is not evidence. Confirmed alternative titles are checked in both directions, and API order applies to the first eligible verified production.

Diagnostics distinguish candidates inspected and rejected from actual download attempts, and record safe rejection categories. A generic failure must not imply a YouTube bot block without an actual bot-check error.

Research owns validation and migration of restored research caches. Script policies invalidate stale writing separately. Model/Python caches, selected voices, encoding settings, storage reserves, source checks and speech/AV verification retain their existing controls. The three repository versions remain separate.

Validation includes mocked identity, release-date, search-budget, plot-context and cache regressions, plus each repository's full GitHub test suite. A bounded live metadata check verifies real title aliases and festival/theatrical dates without AI inference, media downloads or video production. These checks establish software behavior, not subjective video quality.
